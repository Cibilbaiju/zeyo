# Zeyo Backend

Scalable real-time backend for Zeyo (User App) and Zeyo SRV (Provider App).

## Tech Stack
- **Runtime**: Node.js
- **Database**: PostgreSQL (Relational), Redis (Geo/Cache)
- **Messaging**: Kafka (Events)
- **Geo**: H3 Hexagonal Indexing
- **Real-time**: Socket.io

## Setup
1. `npm install`
2. Configure `.env`
3. `npm run dev`
